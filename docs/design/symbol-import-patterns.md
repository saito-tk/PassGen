# 記号読み取りのパターンと境界

タスク25。サービスのパスワード設定画面を模した公開の合成例で検証する。画像は指示ではなくデータとして扱い、適用前の確認を維持する。

| パターン | 例 | 読み取り方針 |
|---|---|---|
| 文の後ろの列挙 | 使用可能な記号: ! @ # | リテラルだけを抽出 |
| 日本語の助詞 | 使える記号は !@# です | 説明文を除く |
| 記号の後ろに許可文 | !@# の記号が使用できます | 記号が文より左でも対応 |
| 日本語の引用・囲み | 記号は「!@#」が使用可能 | 囲みを候補に混ぜない |
| 引用された項目 | 使用可能な記号: '!', '@', '#' | 引用符・区切りのカンマを除く。引用符自体を値にした項目は残す |
| カンマ列挙 | 使用可能な記号: !, @, # | 明確な単独記号の連続項目だけ区切りを除く |
| 説明の括弧 | 使用可能な記号（!@#） | ラベルに直接付く説明括弧は外し、内容にある実際の括弧は残す |
| 名前と実際の字形 | ハイフン（-）、アンダースコア（_） | 目に見える字形だけ。名前から推測しない |
| 名前だけ | ハイフン、シャープ | 字形がない場合は自動で作らない |
| 見出しと次の行 | 使用できる特殊文字 → !@# | 近い後続行を対象にする |
| 短い記号一覧 | 記号: -_ | 完全な許可宣言とは区別した確認候補 |
| 英語 | Allowed symbols / Special characters / … can be used | 否定と区別して対応 |
| 限定許可 | 次の記号以外は使用できません: !@# | 明確な参照を伴う構文だけ限定許可として読む |
| 文字種の表 | 大文字・小文字・数字・記号/特殊文字 | 記号セルだけを選ぶ |
| 折り返し・OCR分割 | 同行の列挙＋次の2行 | 観測順に依存せず行を保持 |
| 幅違い | ！＃＠、＇！＇，＇＠＇ | 値と引用・区切りのASCII全角相当だけ半角化し、元のOCR座標を保つ |
| 禁止一覧だけ | 使用不可: < > | 許可一覧に反転しない |
| 例外を含む規則 | !@# が使えます。ただし # は不可 | 条件を無視した候補は出さず、手動確認へ |
| 正規表現・範囲 | ASCII U+0021〜U+002F、regex [!-~] | 見えない範囲を勝手に展開しない |
| 対応外の字形 | ￥、€ | 別のASCII記号に推測変換しない |
| 入力方法・パスワード例 | 記号/名称/入力するキー、Password example | 許可一覧にしない |
| URL・メール・伏せ字 | URL、メールアドレス、******** | 記号一覧にしない |
| 複数の独立した規則 | ログイン用と取引用が別々 | 無条件に合成せず、対象を絞る案内 |

文字列の表記解析はKotlin共通層、OCRの座標と切り出しはiOS側に置く。元文字列のUTF-16範囲をSwiftへ渡し、全角相当の変換で切り出す座標を変えない。許可文の位置と値の書式を別々に解析し、8種類の文言と7種類の書式の56組合せを共通テストで検証する。

明確な引用・区切りでは、画像モデルや再OCRが書式文字を追加しないよう行ごとに出力可能な記号を絞る。OCRの読めた集合そのものに固定せず、画像モデルは字形を補正できる。記号名と印字が一致した項目だけは、その値に限定する。値そのものが引用符やカンマなら残す。

画像モデルの有効な読取は行ごとにOCRを置き換え、同じ行の異なる画像の候補を合わせる。モデルの候補が空またはOCR候補数から設けた最低数に満たない場合、その行はOCRを維持する。この判定は正確さの保証ではない。引用と直接列挙の混在、隣接した除外条件、未検証の曖昧な表記を部分的な許可一覧として確定しない。

Visionの結果はOSと書体で異なる。iOS 18では引用符が数字や漢字、@が②と誤読される合成画像がある。構文を確定できない場合は理由を表示して手動選択へ進み、候補を得た場合も元画素の照合と追加・解除を残す。iOS 27の対応環境では画像モデルの実推論も検証する。全画像・全文字の完全認識を保証しない。
