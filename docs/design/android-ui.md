# Android UI監査と修正（2026-10-31）

## 監査で見つけた問題

| 問題 | 修正 |
|---|---|
| アプリバー・表示切替・編集・戻るがテキストだけで、操作の区別がつかない | 標準アプリバーとGoogle公式Material Symbolsを採用。生成・保存などはアイコンと文字を併用し、単独のアイコンには日本語の操作名とツールチップ |
| 4文字種の分割ボタン、含めるチェック、全選択・解除が1行へ集中 | 文字種は下線付きタブ。拡大文字では折り返す選択チップ。含めるスイッチと選択メニューを別の行に配置 |
| 文字タイル44dp、状態が背景色だけ、文字種OFFでも選択色が残る | 最小48dp、拡大文字に応じて拡張。選択は濃い枠とチェックを併用。OFFは未使用表示にし、元の個別選択値は保持 |
| surfaceContainerやinverse等が未定義で、シートやツールチップに既定の紫が混在 | 明暗両方のsurface階層・secondary/tertiary・inverse・surfaceTintを定義 |
| 結果の操作と設定の優先順位が平坦 | 条件をカード内でまとめ、結果は既存の別カラム/シートに統一。表示・コピーはアイコン、生成・停止は主ボタン、消去は赤の補助操作 |
| 設定・ガイドで終了までスクロールが必要、見出しの大小が不明瞭 | 閉じる操作付きの見出しを固定。セクション見出しを小さく分け、戻る・外部リンク・QRの共有も共通の操作部品へ統一 |
| 設定が無効な理由が、生成ボタンから離れた場所に表示される | エラーを生成操作の近くへ移し、全文字種0のときの理由を表示・Politeで読み上げる |
| 拡大文字でプレビューの「大文字」が途中で割れ、文字間が詰まる | ラベル幅・文字セル幅・間隔をフォントサイズに追従させる |
| 画面再作成で入力中のプリセット名・記号が失われる | ViewModelのEditorSessionでメモリ内だけ保持し、シート終了・モデル終了で参照を破棄 |
| 設定やガイドのシートが分離ヒンジを横断する可能性 | 共通PassgenSheetが縦・横ヒンジの大きい側を選び、無効・表示範囲外のヒンジは無視 |

## アイコンの出典と扱い

[Android公式の推奨](https://developer.android.com/develop/ui/compose/graphics/images/material)に従い、Google公式のMaterial Symbols OutlinedをAndroid VectorDrawableとして31種類同梱する。旧material-iconsライブラリを追加せず、描画はMaterial 3のIcon/painterResourceで行う。フォントの文字列置換には依存せず、オフラインでも図形を描画する。

固定リビジョン・各素材のURL・SHA-256・軸・RTLは [material-icons.json](material-icons.json) に記録。公式Android版の960単位の輪郭とミラー指定は維持し、AppCompat依存のtint属性だけを除く。色はComposeのLocalContentColorで指定する。Apache-2.0全文をAPKのassets/licensesへ同梱し、設定から閲覧可能。

24単位へ正規化したレビュー用SVGで31件を構造検証し、エラー0。live areaの超過7件、keyのtrim境界1件、QRの複雑さ1件は、公式形状の光学的配置・意味に由来する警告として輪郭を維持した。ブラウザーのローカルHTML表示はURLポリシーにより拒否されたため、HTMLでの確認は行わず、Androidで同じ素材を明暗の実描画・実画面として確認する。

## 状態とセキュリティ

生成エンジン・記号正規化・QR形式・保存内容・保護の初期値は変更しない。表示切替とコピー印はcompositionで読んだ値をアイコンへ渡す。遅延リストのsemantics評価から直接モデルの可変状態を読まない。

単独の操作アイコンは24dp、押下領域は48dp以上。ボタン内の補助アイコンは18dp、チェックは文字と併用する。戻る等のRTLは公式素材の指定に従い、独自の輪郭・未管理ライブラリを追加しない。レビュー画像は専用emulatorのテスト用設定とマスク済み結果のみで、製品の画面保護は維持する。


プリセットの保存名・編集・QR確認の名前と記号貼り付け文は、EditorSessionでActivityの再作成をまたいで保持する。SharedPreferencesやSavedStateHandleへ含めず、シートを閉じる・設定を読み込んで終了する・ViewModelを破棄する時に消去する。プロセス終了後には復元しない。入力消失を再現する2件のテストが修正前に失敗し、修正後には成功した。
