# UI / UX

## 画面密度

ユーザーのフィードバックに基づき、大きな宣伝見出し・英語タグライン・装飾用リング・未生成カードを削除。
メイン画面は生成形式、文字数 / 件数、文字セット、生成ルールに集中する。
説明は操作に必要な範囲に絞り、安全性の詳細は専用シートに置く。
密度を上げても文字の個別選択はiOSで44pt、Androidで44dpの視覚面＋周辺間隔を確保する。

## 生成形式

- パスワード: 大文字・小文字・数字・記号を個別指定する。
- パスフレーズ: EFF 7,776語から6〜12語を無作為に選択する。
- 数字のみは独立した形式にせず、パスワード内の一括設定とする。大 / 小文字・記号を無効、数字0〜9を有効にし、似た文字の除外を無効にする。
- パスフレーズの区切りは半角スペース（初期値）、`-`、`_`、`.`。固定の区切り文字にはエントロピーを加算しない。

## 文字セット

文字種ごとのタブでA〜Z、a〜z、0〜9、ASCIIの32記号を1文字ずつ切り替える。
文字セットの直下に「現在選択中の文字」を置く。大文字・小文字・数字・ASCII32記号をすべて並べ、実際の生成対象を濃色、未選択・文字種無効・似た文字として除外中の文字を淡色で示す。参照専用の一覧とし、選択操作は文字セット側へ集約する。狭い画面では各行を折り返す。文字種全体の有効 / 無効と、各文字の選択状態は独立して保持する。生成ルールは全幅の開閉行にし、ネイティブスイッチをインデントしない。
全選択 / 解除（iOSでは反転も可）を提供する。
似た文字として除外中の文字はグレー表示し、理由を表示する。除外対象自体も生成ルールから個別変更できる。

## 結果シート

生成開始時に下から一覧シートを開き、結果を逐次追加する。
件数に合わせて初期の高さを調整し、多数の結果はスクロール・拡大して閲覧する。
一覧には番号、実文字数、マスクされた結果、個別コピーを置く。強度の数値は共通条件としてまとめる。
表示切替・停止・消去・再生成・閉じるをシート内で操作できる。
閉じても前景中は結果を再表示でき、背景移行時は結果を破棄する。

## OSごとの構成

AndroidはMaterial 3の入力欄・分割ボタン・選択パレットを使用。幅が広い場合は条件と文字セットを分け、縦 / 横のヒンジを避ける。
分離する縦ヒンジでは生成ボタンと結果シートを右側へ配置する。
iOSはSwiftUIのネイティブ分割選択、トグル、開閉行、Listシートを使用。iPadでは条件と文字セットを2ペインで扱う。
Liquid GlassはiOS 26以降の標準ツールバー・シート・主要アクションに使用し、透明度抑制時は不透明な操作面にする。
文字サイズ拡大では折り返し・スクロールを許可し、iPadでもアクセシビリティ文字サイズは1列を優先する。

## 保持とコピー

生成条件・表示状態・保護設定だけを端末内へ保存する。生成結果・読み取り内容・コピー済み状態は保存しない。
マスクは区切りなしの固定長。表示を選んだ場合は再生成でも維持する。コピーは各行のアイコンに✓を添え、複数行のコピー済み状態を保持する。
設定と安全性はメイン画面から常に開ける。iOSでは収録中も設定操作を許可し、保護対象の結果と画像だけを隠す。停止後は表示・コピーを再開できる。
安全な使い方は設定とは別の読み物ページへ置き、公式のヘルプへリンクする。
