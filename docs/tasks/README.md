## 07 / 08 / 10 変更と検証

- 生成条件・文字の個別選択・表示状態・保護設定を端末内保存。再生成や形式切替で条件と表示状態をリセットしない。生成結果・コピー済み行IDは保存しない。
- 空白なしの共通マスクへ変更。コピーアイコンは残し、行ごとの✓を重ねる。他の行をコピーしても印を維持し、再生成・結果消去・背景移行で破棄。
- iOSはUIKitのsceneCaptureStateを監視し、非アクティブからの復帰時にも再読取。収録中でも設定操作を許可し、保護する結果と画像だけを隠す。停止時の復帰をtrait overrideで検証。
- 生成ルールのネイティブスイッチを全幅に配置。開閉ヘッダの余白もタップ可能にする。文字セットの直下に4文字種の使用状況と実効文字数を表示。
- コピー自動消去5〜600秒、時間による消去の有効/無効、背景消去、画面保護を保存して反映。iOSはUniversal Clipboard共有を選択可能。初期値は端末内限定・30秒・背景消去・画面保護オン。
- iOSの静止画禁止は提供せずOS制約を明記。Androidは端末内コピー限定の共通APIがないためOS側で共有を管理する旨を明記。
- 設定変更は次のコピーから適用。所有識別と他アプリのコピーの維持、設定した5秒での消去をネイティブテストで確認。
- AndroidのWindowフラグは状態をcomposition中に読み取ってSideEffectへ渡す。フラグが実際にオン/オフへ追従することを確認。

## 09 変更と検証

- 日本語OCRによる角括弧・波括弧などの誤認、許可文と無関係なフッターの禁止表現による候補拒否、英語の区切りを全角コロンとして認識するケースを修正。
- 許可文を特定し、記号行だけを英語OCRで再読取。字形は変更せず間隔を追加した画像でも認識。Visionの行配列を画像内の位置で並べ直す。
- iOS 27のFoundation Modelsの画像Attachmentで、OCRテキストだけでなく各記号行の画像をSystemLanguageModelへ直接渡す。クラウドやツールは使用しない。
- 全ASCII32記号へ対応を拡張（既存30＋バッククォート・バックスラッシュ）。元の切り取り画像と全記号のパレットを並べ、欠落分の追加・余分な候補の解除後に適用。適用時に記号の文字種も有効化。
- 添付画像はMac上の端末内モデルを使った最終処理で、指定された31記号と集合一致（不足・追加とも0）を確認。iPhone実機のモデル精度は未検証。
- 記号の案内部分だけを埋め込んだ回帰フィクスチャで、端末内OCR・プレビュー・許可文・2行分の候補と対応文字への制限をテスト。OCR単体の完全認識は保証しない。モデルが使えなくても全32記号を修正・適用できる。
